Star Schema Data Model Architecture

1 Fact table (`FactOrders`) joined via 1-to-Many single-directional relationships to 4 normalized Dimension tables.

[DIMENSIONS] ────(1)─────────────(*)────> [FACT]
• DimCustomer (793 customers) ───────────> FactOrders (9,994 rows)
• DimProduct (1,862 items) ───────────────> FactOrders (Sales, Quantity, Discount, Profit)
• DimGeography (531 cities, 4 regions) ───> FactOrders (Shipping Costs, Delivery Performance)
• DimDate (1,238 active transaction days) ─> FactOrders (Time Intelligence: YTD, YoY, MoM)

Core DAX Business Measures

Engineered DAX formulas powering executive reporting and time intelligence.

// Total Sales Metric
Total Sales = SUM(FactOrders[Sales])

// Total Profit & Margin
Total Profit = SUM(FactOrders[Profit])
Profit Margin % = DIVIDE([Total Profit], [Total Sales], 0)

// Year-over-Year Growth Measure
Sales YoY Growth % =
VAR PrevYear = CALCULATE([Total Sales], SAMEPERIODLASTYEAR(DimDate[FullDate]))
RETURN DIVIDE([Total Sales] - PrevYear, PrevYear, 0)
